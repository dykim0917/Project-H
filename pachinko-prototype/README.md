## v3 — 핀 디테일과 스테이지

사용자가 제공한 카페테라스 판면 이미지에서 핀의 부채꼴 군집, 유도 줄, 투명한 하단 구조를 참고했습니다. 원본 이미지를 게임에 삽입하거나 실제 핀 좌표를 추출한 것은 아닙니다. 둥근 황동 핀 머리·축·그림자, 투명 통로와 곡면 선반, 중앙 낙하 홈을 자체적으로 그립니다.

스테이지 입구는 (116,396), 선반은 x=176..391이며 중앙 홈은 x=268입니다. 실제 입구 통과 시에만 진입하며 진입 속도, 곡면 경사와 감쇠로 좌우 이동과 중앙/옆 낙하가 결정됩니다. 중앙으로 내려온 뒤에도 자유 구간 물리와 하단 핀을 지나 START를 통과해야 입상합니다.

스테이지는 통로에 구속된 이동 및 곡면 위 1차원 구름을 사용한 2.5D 근사입니다. 완전한 3D 물리나 실기 스테이지의 복제는 아니며, 스테이지 위 구슬끼리의 충돌은 생략했습니다. 자유 구간의 구슬 충돌은 유지됩니다.

하단 확대 화면, 스테이지 ON/OFF, 진입/중앙/옆 낙하 카운터를 추가했습니다. ON/OFF는 기존 비교 초기화 규칙을 따릅니다. 이전 v2는 archive/v2/에 있습니다.

검증: 10개 로직 테스트 통과. 스테이지 입구의 실제 통과, OFF 우회, 속도에 따른 두 출구, 중앙 낙하 시 입상 미집계, 자연 발사의 스테이지 진입과 전 구슬 배출을 포함합니다. 브라우저 자동 화면 확인은 관리 정책 확인 서비스 오류로 계속 불가합니다.

## v4 — 발사 핸들과 우타 경로

- 핸들을 오른쪽/위로 드래그하거나 슬라이더·방향키로 발사 세기를 조절합니다. 좌타 기준 36%, 우타 기준 90% 버튼은 세기만 설정합니다. 세기 변경은 다음 발사부터 적용되고, 0%에서는 추가 발사를 하지 않습니다. 0.6초 발사 주기는 유지합니다.
- 공통 레일 끝에서 구슬의 초기 속도를 힘에 따라 계산합니다. 상부를 가로질러 오른쪽에 도달하는 경로는 중력과 충돌의 결과입니다. 오른쪽 핀과 경로 확인용 통과구를 추가했습니다. 우타 통과는 횟수만 기록하며 입상 보상·보류·RUSH를 추가하지 않습니다. 기존 중앙 헤소의 시험 ST 규칙은 유지합니다.
- 자유 구간의 구슬 충돌을 유지하고, 완전히 겹친 중심도 분리합니다. 스테이지에 접선 방향의 충격량 교환과 겹침 보정을 추가했습니다. 발사 레일에도 추월 방지를 추가했습니다. 충돌 횟수는 미세한 접촉 떨림을 제외합니다.
- 스테이지 중앙 홈은 나란히 놓인 구슬의 불필요한 정체를 줄이도록 19 단위로 넓혔습니다.
- 자유 구간·스테이지·구속 통로는 서로 다른 물리 구간입니다. 스테이지가 실제 3D 깊이까지 계산하는 모델로 바뀐 것은 아닙니다. 레일은 구속 경로이며 발사 힘과 실제 실기 핸들의 대응 수치는 자체 시험값입니다.

검증: 14개 로직 테스트 통과, HTML 컨트롤 연결 및 서버 응답 확인. 추가 검사는 자유 구간/스테이지 충돌, 초기 속도와 발사 위치, 세기에 따른 우타 증가, 발사 후 힘 불변, 핸들/키보드/슬라이더, 0% 발사 정지를 포함합니다. 브라우저 도구는 관리 정책 확인 오류가 지속되어 실제 화면과 포인터 조작의 최종 검증은 미완료입니다. v3 백업: archive/v3/.

## v5 — 진입 난도·미세 핸들·기계음·도안 회전

- 스테이지 입구 폭을 24에서 15로 줄이고 (111,380)에 핀을 추가했습니다. 통과 뒤 확률로 거절하는 방식이 아니라 입구와 핀의 실제 배치를 변경했습니다.
- 핸들은 0.5% 단위로 조절하며 미세 조절 버튼을 추가했습니다. 36~60% 구간의 발사 속도 변화 폭을 완만하게 했습니다. 모든 세기의 경로는 같은 물리 계산에서 나오므로 핸들 수치가 특정 경로·입상을 보장하지 않습니다. 36%와 90%의 발사 속도는 기존과 같습니다.

## v6 — HUD와 좌우 화살표 핸들

화면은 상단 회전·대당첨·획득 구슬·ST HUD, 판면, 하단 조작부로 정리했습니다. 설명 문단, 별도 확대 화면, 관찰 통계, 기록 패널, 테스트 버튼, 볼륨 슬라이더, 좌타/우타 프리셋을 제거했습니다. 발사·소리·배속·초기화만 남겼습니다. 물리와 추첨 설정은 v5 그대로입니다.

핸들 양옆의 화살표를 짧게 누르면 0.5%씩 조절합니다. 0.35초 이상 누르면 반복하고, 1.3초 이후에는 빠르게 조절합니다. 손을 떼면 설정값을 유지합니다. 기존 드래그와 슬라이더를 없애고, 핸들에 포커스한 상태의 방향키 및 Home/End 접근성 조작은 유지했습니다. 길게 누르기의 속도는 게임 배속과 무관하며 손 떼기·포인터 취소·캡처 상실·창 포커스 상실·배경 전환·초기화에서 중단됩니다.

검증: 로직 테스트 20개 통과. 실제 HTML에 존재하는 요소만 반환하도록 DOM 대역을 강화했고 화살표 단타/연타 중복 방지, 길게 누르기, 취소, 배속 독립성, 0~100% 경계와 기존 구슬 속도 유지를 확인했습니다. 최신 HUD의 로컬 서버 응답도 확인했습니다. 실제 화면 확인은 브라우저 보안 정책 확인 서비스 오류로 완료하지 못했습니다. v5 백업: archive/v5/.

## v7 — 하단 끼임과 둥근 상단 유도벽

왼쪽 아래 (115,485) 부근에서 대각 유도벽과 (121,488) 핀 사이에 구슬이 끼는 현상을 재현했습니다. 여러 구슬이 쌓였고, 기존 18초 만료 처리가 일부 정체를 가리고 있었습니다. 하단 유도벽을 (30,460)→(197,575)로 옮겨 통과 여유를 확보하고, 스테이지 입구 앞의 촘촘한 핀도 (111,380)→(115,378)로 옮겼습니다. 회전못이나 임의의 탈출 힘은 추가하지 않았습니다.

LCD는 사각형을 유지하며, 그 위의 물리 유도벽은 타원형 덮개로 분리했습니다. 외곽 천장도 둥근 곡선으로 변경했습니다. 표시하는 곡선과 충돌 선분은 동일한 좌표를 사용합니다. 발사 속도를 새 구조에 맞게 조정했으며, 좌우 경로는 힘·중력·벽 충돌로 결정됩니다.

발사구에는 단방향 역류 방지판을 추가했습니다. 구속 레일에서 구슬이 통과하면 판에 개방 운동을 주고 스프링/감쇠로 복귀하며, 되돌아오는 자유 구슬은 현재 판 위치와 충돌합니다. 완전한 다물체 힌지·운동량 교환 모델은 아니며, 판을 통과할 때 임의의 좌타/우타 판정을 하거나 발사 힘을 별도로 감산하지 않습니다. 실기의 동일 부품을 식별한 것은 아닙니다. 역할 참고: https://patents.google.com/patent/JP5394859B2/ja

만료 안전장치는 60초로 늘리고 out 이벤트에 종료 이유를 표시했습니다. scripts/check-flow.cjs로 36%·55%·90% 각각 세 시드에서 200발씩, 총 1,800발을 시험했습니다. 전 구슬이 입상 또는 배출됐으며 만료 0개, 잔류 0개, 최대 체류 16.35초였습니다. 원자료는 reports/v7-flow.json입니다. 표본 범위의 결과이며 실기 보더나 모든 핸들 설정에 대한 보장은 아닙니다.

검증: 기존 검사와 추가 회귀 검사 총 23개 통과(전체 실행 중 타이밍에 의존하던 방지판 검사 1개 수정 후 해당 검사 재실행). 추가 검사는 이전 끼임 위치의 다중 구슬 자연 배출, 중간 세기의 좌측 복귀/강한 세기의 우측 통과, 방지판 개방·복귀·역방향 충돌입니다. 앱 검사에서는 첫 입상 시점이 달라져도 회전 완료까지 기다린 뒤 집계가 증가하는지 확인하도록 개선했습니다. 문법 및 미리보기의 최신 파일 응답 확인 완료. 브라우저 보안 정책 확인 서비스 오류가 이어져 실제 화면의 시각 검증은 미완료입니다. 이전 버전: archive/v6/.

## v8 — 큰 LCD와 좁은 핀 통로
