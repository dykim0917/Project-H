# Mk.IV — 황동 구슬공방

[실행](http://127.0.0.1:8765/mark4/) · Windows는 저장소 루트의 START-MK4.bat 또는 START.html.

Mk.III의 물리·추첨·지급·음향을 공유해 자매 기계 제작 가능성을 시험합니다. 밝은 청록 에나멜과 황동 실린더가 평상시 압력을 표시하고, 최초 당첨 뒤 두 실린더가 옆으로 열립니다. 내부의 세 보관통이 순서대로 열려 구슬을 중앙 분기 장치로 보내고, KEEP 통로에 한 알이라도 도착하면 변형을 유지하며 연장합니다.

## 공통 부분과 차이

- 공통: Mk.2.5 외부 판면, Mk.III 일반 추첨·상태 전이·지급 받침·합성음. Mk.III 파일은 변경하지 않았습니다.
- 차이: 압력 실린더와 게이지, 좌우 개방, 3개 보관통의 순차 방출, 분기 게이트와 두 수거통, 개별 방출음.
- 초기 당첨 1/29, 낙첨 리치 10%, 당첨당 300개·약 5초 지급, 러쉬 각 구슬 38%·종합 76.1672%를 그대로 유지했습니다. 기계 인상 차이를 먼저 비교하는 기준이며 등급 성능 차이는 없습니다.
- 러쉬 방출은 시작 후 0.3 / 1.4 / 2.5초, 각 결과는 1.6 / 2.7 / 3.8초, 도전 판정은 공통 4.7초입니다. 여러 성공도 한 번만 연장·지급합니다.
- 구슬 분류 결과는 시작 때 미리 추첨하고 경로로 표현합니다. 내부 저장·분기 장치는 실제 자유 구슬 물리나 접촉 판정이 아닙니다. 외부 핀·발사·충돌은 기존 물리를 공유합니다.
- 배속 없음. 체험은 기록 초기화 후 최초 당첨 진입. 탭 숨김은 일시정지입니다.

## 범위

기계별 부품·성급·가챠·수집 효율, 방, 오프라인 정산은 구현하지 않았습니다. 이번 작업은 공유 기반으로 새로운 장치 경험을 만들 수 있는지 시험하는 기계 시제품입니다. 최근 논의한 독립 지급 대기열·라운드 지급도 아직 공통 엔진에 반영하지 않았습니다.
