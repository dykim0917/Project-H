# Mk.2.5 — 별빛 회전극장

실행 주소: http://127.0.0.1:8765/mark25/

작은 숫자창과 기계식 룰렛 리치 연출을 결합한 시제품입니다. Mk.I·Mk.II는 그대로 남겨두었습니다. 영상·외부 이미지·음원 없이 Canvas와 합성음으로 표현합니다.

## 동작

- 좌우 START 입상으로 추첨을 대기시킵니다. 최대 보류 4개이며 진행 중인 회전과 별도입니다.
- 숫자는 좌측, 우측 순서로 정지합니다. 두 숫자가 맞으면 5.8초 동안 중앙 기계식 룰렛이 회전하고 감속하며 마지막 숫자를 확정합니다.
- 추첨은 회전 시작 시 1/29로 결정합니다. 시제품 체험을 위한 확률이며 실제 기종 사양이 아닙니다. 낙첨 중 10%는 리치 연출을 거칩니다.
- 룰렛은 추첨 결과를 표현하는 장치입니다. 구슬이 실제로 룰렛을 돌리거나 물리 V입상으로 당첨되는 방식은 아닙니다. 포인터 아래 숫자와 최종 숫자창이 일치합니다.
- 당첨 시 셔터가 열리고 5초 동안 300개를 지급합니다. 구슬 샤워는 지급량에 동반되는 장식이며 판면의 물리 구슬과 별도입니다. 시동 입상 지급 1개도 누적합니다.
- 보너스 동안 들어온 보류는 종료 후 처리합니다. 리치·낙첨·당첨에 따른 추가 조작은 없습니다.

발사 세기 기본값은 36%입니다. 좌우 화살표로 조절하고, 길게 누르면 반복합니다. ×3은 구슬과 연출 전체에 적용됩니다. 숨겨진 탭은 전체 시뮬레이션을 멈춥니다. 초기화는 현재 추첨·보류·지급·구슬·기록을 초기화하며 선택한 세기를 유지합니다.

## 구조와 확인

`game.js`는 추첨·리치·지급 상태와 Mk.II 물리 연결을 담당합니다. Mk.II 외부 판면·핀·구슬 충돌을 재사용하고 날개는 닫힌 상태로 고정합니다. `app.js`는 숫자창·룰렛·셔터·조명·소리와 조작부를 담당합니다. 상위 폴더의 공용 발사 레일과 음향 파일이 필요합니다. 판면 물리는 이 폴더의 physics.js로 분리했으므로 Mk.II의 시동구는 바뀌지 않습니다.

상위 폴더에서 `node --test mark25/game.test.cjs` 실행: 검사 10개 통과. 당첨·낙첨·리치 낙첨, 최종 룰렛 위치, 보류 순차 소비, 지급 중복 방지, 실제 시동 입상 연결, 초기화, 탭 일시정지와 핸들을 확인했습니다. 세기 36%·55%·90%에서 각 200발씩 총 600발은 잔류와 시간 만료 없이 배출됐습니다.

DOM/Canvas 검사는 대역을 사용했습니다. 브라우저 정책 확인 도구 장애가 이어져 실제 화면·소리를 직접 확인하는 검증은 미완료입니다. 저장, 오프라인 수익, 랭킹, 실기 출옥률 조정은 포함하지 않습니다.

## 밸런스 조정 1

시동구 표시·판정 폭을 32에서 14로 줄였습니다. 시동 입상을 임의의 확률로 취소하지 않으며 실제 구슬 위치와 입구 폭으로 판정합니다. 주변 가이드는 유지했습니다. Mk.II는 별도 원본 물리를 계속 사용합니다.

대당첨 확률 1/19 → 1/29, 낙첨 시 리치 비율 24% → 10%로 조정했습니다. 전체 회전의 이론상 리치 빈도는 28% → 약 13.1%, 리치 중 당첨 비율은 약 18.8% → 26.3%입니다. 매 회전 독립 추첨이며 장시간 미당첨에 따른 보정은 없습니다. 당첨 지급 300개와 발사 속도는 유지합니다. 기기 계기에 현재 1/29를 표시합니다.

`node mark25/check-balance.cjs` 비교 결과는 `reports/balance.json`에 있습니다. 양쪽 입구 폭 모두 새 추첨 설정을 사용하고 구슬과 추첨의 난수열을 분리해 형상 효과를 비교했습니다. 36%·55%·90% × 3개 시드 × 입구 폭 2종, 각 300발로 총 5,400발이며 잔류·시간 만료 0개입니다.

기본 세기 36%에서 900발당 시동 입상 469 → 90회(52.1% → 10.0%). 발사 중 실제 추첨은 총 9분에 138 → 82회, 즉 약 15.3 → 9.1회/분입니다. 초반 10초를 제외한 보류 포화 시간은 72.4% → 1.7%, 추첨과 보류가 모두 없는 시간은 0% → 36.7%였습니다. 55%에서도 입상 93/900으로 비슷했습니다. 90%는 우측으로 빠져 입상이 매우 드물었습니다.

검사 10개 통과. 실제 입구 안/밖 판정과 10만 회 추첨의 당첨·리치 비율 검사를 추가했습니다. 위 회전수는 발사 중 경과시간 기준이며 상구 재사용이나 대여 구슬을 계산한 천 엔당 회전율이 아닙니다. 실제 화면·소리 직접 검증은 미완료입니다.
