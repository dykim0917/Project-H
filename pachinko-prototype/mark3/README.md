# Mk.III — 변형 러쉬

http://127.0.0.1:8765/mark3/

Mk.2.5의 일반 숫자 추첨에, 기계가 열린 채로 유지되는 러쉬와 받침에 쏟아지는 구슬·합성음을 추가한 시제품입니다. 이전 기기는 수정하지 않았습니다.

## 흐름과 수치

일반 당첨(1/29) → 잠금 해제와 짧은 간격 → 300개 지급 → 중앙 숫자 룰렛이 접히고 양쪽 프레임이 벌어짐 → 내부 회전 접시에서 세 구슬의 연장 도전.

각 구슬의 최종 각도를 독립적으로 뽑고, 원의 38%인 초록 구역에 한 알이라도 도착하면 연장합니다. 라운드당 연장 확률은 1 - 0.62³ = 76.1672%입니다. 성공하면 300개를 한 번 지급하고, 변형을 유지한 채 다음 도전을 시작합니다. 세 알 모두 성공해도 지급은 한 번입니다. 실패하면 프레임이 닫히고 일반 추첨으로 복귀합니다. 첫 당첨을 1연짱으로 표시합니다. 최대 연짱 제한은 없습니다.

러쉬 내부는 확률 추첨 결과를 궤도와 감속으로 표현한 간이 모델입니다. 실제 다물체 물리로 접시의 최종 위치를 결정하는 모델은 아닙니다. 펼쳐지는 장치는 외부 핀 구간과 분리된 내부 깊이의 표현이며 외부 판면의 충돌체를 이동시키지 않습니다. 정상 시동구·입상률·일반 추첨은 Mk.2.5 밸런스를 유지합니다. 앞서 논의한 넓은 가이드와 좁은 헤소의 경로 재설계는 이번 버전에 포함하지 않았습니다.

## 지급과 소리

지급 구슬은 5개당 한 개의 시각 입자로 표현하며 중력과 받침·측벽 반사를 적용합니다. 바닥 충돌 이벤트에 금속 고음과 받침 울림을 연결했습니다. 지속적인 구슬 흐름 소리, 개폐 모터음, 잠금 해제음은 합성음입니다. 녹음한 실제 파칭코 지급음은 사용하지 않았습니다. 입자는 마지막에 정리하고 받침에 남는 표시는 36개로 제한합니다. 구슬 간 쌓임의 완전한 물리 모델은 아닙니다.

## 조작

‘러쉬 체험’은 현재 시제품 기록을 초기화하고 첫 당첨부터 바로 보여줍니다. 체험 중 상태줄에 ‘체험’을 표시합니다. 초기화하면 일반 모드로 돌아갑니다. 이 버튼은 일반 추첨 확률을 바꾸지 않습니다.

발사·좌우 세기·소리 조작을 제공합니다. 배속 버튼과 속도 배율을 제거했으며 구슬·장치·지급은 기본 속도로 고정합니다. 숨겨진 탭에서는 시간이 멈추고 지속음도 꺼집니다. 초기화 시 변형·보류·지급·입자를 모두 정리합니다.
