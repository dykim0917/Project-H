# 기계 수집·성급 — 후속 논의 메모

2026-09-09 · GDD v0.6 이후 대화 기록. 정식 경제 사양이나 구현 완료 문서가 아니다.

## 사용자가 제시한 방향

- 기계 획득을 가챠로 구성하고 원하는 기계 구매 역할은 지정 천장으로 제공하는 방향을 검토한다.
- 기계마다 등급별 효율을 두고, 컬렉션이 늘면 생산 효율이 올라가는 구상을 검토한다.
- 중복 기계는 해당 기계 부품으로 제공하고 부품을 사용해 성급을 올리는 방향이다.
- 장면 영상 대량 제작보다 기계식 장치 변화를 활용한 자매 기계를 만들고, 제작 가능성을 Mk.IV로 시험한다.

## 미정

뽑기 재화·확률·가격, 유료 여부, 천장 횟수·이월, 등급 수와 효율, 중복 부품 수량·성급 비용·상한·상한 이후 중복, 낮은 등급의 장기 사용 가치, 가동 기계 성능과 보유 컬렉션 효과의 배분은 미정이다. 에너지 생산 세계관 자체도 확정하지 않았다. 등급(획득 분류)과 성급(중복 성장)을 구분한다.

## 이번 구현

Mk.IV ‘황동 구슬공방’은 Mk.III 공통 기반의 저장·순차 방출 자매 기계다. 확률·지급량은 비교를 위해 Mk.III와 동일하다. 가챠·등급·부품·성급은 이번 구현에 포함하지 않았다. [구현 설명](../pachinko-prototype/mark4/README.md).

## 추가 기계 후보 — 좌타 유지·가변 날개 입구

사용자가 통상과 러쉬에 별도 좌·우타를 요구하지 않고 기존 입구의 날개가 통상에는 열렸다 닫히고 러쉬에서는 길게 열려 있는 기계를 제안했다. 특정 우미모노가타리 기종과 동일한 구조인지 확인한 것은 아니다.

가상 기계 후보로는 발사 방향을 유지하면서 입구의 수용 폭·개방 시간과 입상 역할이 상태에 따라 바뀌는 구조를 검토한다. 실제 입상을 받아 충전·라운드 지급을 진행하는 원칙은 유지한다. 항상 열린 입구의 과잉 입상·라운드별 개수 제한·헤소와 지급구의 역할 구분은 별도 설계한다. 현재 Mk.IV 우타 구조를 이 방식으로 교체하거나 새 기계를 구현한 것은 아니다.
