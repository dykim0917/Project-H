# MARK II — 별빛 유원지

큰 LCD와 추첨 연출을 기계식 날개·투명 내부 선반·움직이는 V존으로 바꾼 오리지널 시제품입니다. Mk.I 파일은 유지하며, 같은 서버의 `/mark2/`에서 실행합니다.

## 놀이 흐름

1. 좌우 하단 START에 구슬이 들어가면 시동 횟수가 증가하고 날개가 열립니다. 일반 상태의 개방 대기는 최대 4개입니다.
2. 열린 날개 사이로 들어간 구슬은 내부 통로와 선반을 따라 이동합니다.
3. 좌우로 움직이는 V존에 하강 중 실제로 들어가면 대당첨입니다. 별도 확률 추첨으로 당첨을 정하지 않습니다.
4. 당첨 중에는 V존이 중앙에 고정됩니다. 날개가 반복 개폐하며 중앙에 도달한 구슬을 최대 5개 모읍니다.
5. 6.8초가 지나거나 5개가 모이면 저장문을 열어 구슬을 놓습니다. 해당 라운드 구슬이 방출 단계에 V존을 통과하면 다음 라운드로 이어지며, 실패하거나 8라운드를 마치면 일반 상태로 돌아갑니다.

시동 입상 +1개, 최초 대당첨 +50개, 보너스 중 날개 입상 +10개를 누적 표시합니다. 테스트용 지급량이며 순수익이나 실기 출옥률을 의미하지 않습니다. 현재 구슬 소진 제한, 저장, 오프라인 수익, 랭킹은 없습니다.

## 조작과 표현

- 발사 시작/정지, 소리 ON/OFF, 전체 ×1/×3, 초기화만 제공합니다.
- 핸들 좌우 화살표를 짧게 누르면 0.5%씩 조절하고, 길게 누르면 반복합니다. 방향키와 Home/End도 지원합니다.
- 초기 세기는 36%입니다. 강하게 발사하면 상단 레일을 넘어 우측으로 갈 수 있습니다.
- 화면을 벗어난 탭에서는 구슬과 장치 시간이 함께 멈춥니다.
- 조명, 7세그먼트 숫자, 힌지 날개, 저장문을 Canvas로 그리고 기존 합성음을 활용합니다. 영상이나 상용 기종의 이미지·음원은 사용하지 않습니다.

## 모델 범위

자유 구간은 중력과 핀·벽·구슬 충돌을 사용합니다. 발사 레일과 내부 연결 통로는 정해진 경로를 따라 이동하며, 선반은 경사·속도를 계산하는 단순화된 모델입니다. 외부 구슬과 내부 구슬은 서로 다른 깊이로 처리합니다. 날개는 구동 각도에 따라 움직이는 선분 충돌체이며 실제 모터·힌지의 완전한 동역학 모델은 아닙니다.

닫히는 날개 또는 다른 구슬이 자유 구슬을 몸체 내부로 밀어 넣지 않도록 몸체 외곽을 막힌 영역으로 처리합니다. 보너스와 라운드마다 입상 구슬을 구분해 이전 라운드의 늦은 구슬이 중복 당첨을 만들지 않게 했습니다. 이 규칙과 수치는 특정 실기의 복원이 아닌 가상 기기의 설계입니다.

## 확인 방법

`node --test mark2/machine.test.cjs` (상위 pachinko-prototype 폴더에서 실행).

구슬 보존·시동·날개 입상·물리 V판정·끼임 회귀·중복 당첨 방지·저장 및 방출·라운드 종료·발사 정지·HUD·배속·탭 일시정지·핸들을 검사합니다. DOM과 Canvas 검사는 대역을 사용한 로직 검사입니다. 연속 발사 수치는 `reports/flow.json`에 저장합니다.

브라우저 정책 확인 서비스 장애로 실제 화면과 소리를 브라우저에서 확인하는 검증은 미완료입니다.

최종 결과: 검사 12개 통과. 36%·55%·90% × 3개 시드, 각 300발씩 총 2,700발에서 잔류·시간 만료 0개. 기본 세기 36%의 각 표본에서 최초 대당첨 2~3회가 발생했습니다. 90%에서는 날개 입상이 없었습니다. 표본 수치는 밸런스 보장이 아니며 핀·날개 시간·선반 형상을 바꿔 조정할 수 있습니다. 모든 페이지와 스크립트의 로컬 서버 응답 및 스크립트 문법도 확인했습니다.
