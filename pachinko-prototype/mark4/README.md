# Mk.IV — 황동 구슬공방

[실행](http://127.0.0.1:8765/mark4/) · Windows: 저장소 루트 START-MK4.bat 또는 START.html.

## 좌타·우타와 실제 입상

기본은 ‘전환 자동’입니다. 통상 세기 36%, 당첨~러쉬 구간 95%로 자동 전환하고 종료 뒤 좌타로 돌아옵니다. ‘전환 수동’ 버튼 또는 핸들 화살표 조작으로 수동 세기를 유지할 수 있습니다. 자동 버튼을 다시 켜면 현재 상태에 맞는 세기로 즉시 돌아갑니다. 발사 시작/정지는 별도입니다.

당첨 뒤 우측 아타커가 열립니다. 외부 판면에서 발사한 자유 구슬이 열린 입구를 아래 방향으로 통과해야 입상으로 인정합니다. 구슬 한 개는 한 번만 소비하며 닫힌 상태·입구 밖·위 방향 통과는 인정하지 않습니다. 기존 기계와 공통 물리에는 선택적 입상 처리 지점만 추가했습니다.

## 지급 라운드

시제품 설정: 5라운드 × 4개 입상 × 입상당 15개 지급 = 총 300개. 각 라운드는 네 번째 입상 후 닫히고 0.5초 뒤 다음 라운드를 엽니다. 지급 속도는 초당 최대 60개입니다. 입상으로 확정된 상구를 대기열에 추가하고 속도 제한에 따라 받침으로 지급합니다.

발사를 멈추면 비행 중 구슬은 계속 움직이고 이미 적립된 지급은 끝까지 처리합니다. 새로운 입상이 없으면 라운드는 기다립니다. 실기의 시간제 폐쇄·미입상에 따른 보상 소멸은 적용하지 않은 방치형 시험 규칙입니다. 당첨만으로 자동 300개를 지급하던 방식은 제거했습니다.

## 변형 러쉬

최초 5라운드 입상 완료 → 실린더가 양옆으로 개방 → 우타로 세 알 충전 → 저장통 순차 방출 → 한 알이라도 KEEP이면 연장, 다시 5라운드 지급. 실패하면 닫고 통상으로 돌아옵니다. 충전에도 실제 우측 입상이 필요하며 세 알 이후 추가 충전은 받지 않습니다. 러쉬 중 헤소 입상은 새 통상 보류를 추가하지 않습니다.

일반 당첨 1/29, 낙첨 리치 10%, 러쉬 각 구슬 38%·합성 76.1672%는 유지합니다. 단, 실제 입상 시간이 추가되어 시간당 수익과 체감 속도는 이전 버전과 다릅니다. 저장한 세 알의 내부 경로는 추첨한 결과를 보여주는 애니메이션이며 별도의 물리 V추첨은 아닙니다.

## 조작과 범위

‘러쉬 체험’은 기록 초기화 후 첫 당첨부터 자동 우타 발사를 시작합니다. 무료 지급이나 충전 생략은 없습니다. 초기화는 자동 전환 설정과 기록을 초기 상태로 돌립니다. 배속은 없고 숨긴 탭은 일시정지합니다.

기계 가챠·등급·중복 부품·성급, 방·저장·오프라인 정산은 미구현입니다. 지급 대기열은 세션 안에서만 유지되며 탭을 닫아도 저장하는 기능은 아직 없습니다. 일반 추첨과 러쉬의 전환은 기존 상태 구조를 유지하며, 독립 다중 당첨 시스템 전체를 구현한 것은 아닙니다.

## 검증

Mk.IV 7개 및 Mk.III·Mk.2.5 회귀 검사 합계 26개 통과. 무입상 무지급, 5×4 입상당 정확한 지급, 속도 제한, 실제 입구 판정·중복 소비 방지, 3개 충전과 순차 방출, 자동 좌우 전환·수동 유지, 체험·초기화·숨김을 확인했습니다. 고정 표본 90초 자연 발사에서 최초 지급 300개·우측 입상 23개·충전/러쉬/통상 복귀·시간 초과 구슬 없음 확인.

UI 검사는 DOM·Canvas 대역입니다. 브라우저 정책 확인 서비스 장애가 앞선 작업에서 발생해 이번 실제 화면·스피커 체감은 직접 검증하지 않았습니다. 공통 추첨·판면·음향 기반을 재사용하지만 app.js의 공통 그리기는 일부 복제되어 있습니다.
